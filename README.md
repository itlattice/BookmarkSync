# BookmarkSync

[简体中文](./README_CN.md) | English

## 📖 Overview

**BookmarkSync** is a Chrome browser extension for bookmark synchronization. This repository is dedicated to collecting user feedback, bug reports, and feature suggestions.

🔗 **Extension Repository**: [ly-bookmark](https://github.com/yourusername/ly-bookmark) (Private development repository)

## 🎯 Purpose

This repository serves as:

- 🐛 **Bug Tracker**: Report issues and technical problems
- 💡 **Feature Requests**: Suggest new features and improvements
- 📋 **Feedback Hub**: Share your experience and suggestions
- 📢 **Announcements**: Stay updated with version releases and important notices

## ✨ Features

- 🔄 **Cross-browser Sync**: Seamlessly synchronize bookmarks across devices
- 🔒 **Secure Storage**: Your bookmarks are encrypted and stored safely
- ⚡ **Real-time Updates**: Changes sync instantly across all connected browsers
- 🎨 **Modern UI**: Clean interface built with Vue 3 and Element Plus
- 🌐 **Multi-language**: Supports multiple languages (Chinese, English)
- 📦 **Export/Import**: Backup and restore your bookmarks easily

## 🚀 Installation

### Chrome Web Store (Coming Soon)

The extension will be available on the Chrome Web Store soon.

### Manual Installation

1. Download the latest release from [Releases](../../releases)
2. Unzip the file
3. Open Chrome and navigate to `chrome://extensions/`
4. Enable "Developer mode" in the top right
5. Click "Load unpacked" and select the unzipped folder

## 📝 How to Submit Feedback

### 🐛 Bug Reports

When reporting a bug, please include:

1. **Chrome Version**: Your Chrome browser version
2. **Extension Version**: Found in `chrome://extensions/`
3. **Steps to Reproduce**: Detailed steps to reproduce the issue
4. **Expected Behavior**: What you expected to happen
5. **Actual Behavior**: What actually happened
6. **Screenshots**: If applicable

[→ Report a Bug](../../issues/new?template=bug_report.md)

### 💡 Feature Requests

When suggesting a feature:

1. **Use Case**: Describe the problem you're trying to solve
2. **Proposed Solution**: Your idea for implementing the feature
3. **Alternatives**: Any alternative solutions you've considered
4. **Additional Context**: Screenshots, mockups, or examples

[→ Request a Feature](../../issues/new?template=feature_request.md)

## 🏗️ Technical Stack

- **Framework**: Vue 3 + TypeScript
- **UI Library**: Element Plus
- **Build Tool**: Webpack 5
- **Manifest**: Chrome Extension Manifest V3
- **Architecture**: Multi-process communication with Channel system
