# BookmarkSync

简体中文 | [English](./README.md)

## 📖 项目简介

**BookmarkSync（书签同步）** 是一款 Chrome 浏览器书签同步扩展程序。本仓库专门用于收集用户反馈、bug 报告和功能建议。

🔗 **扩展程序主仓库**: [ly-bookmark](https://github.com/yourusername/ly-bookmark)（私有开发仓库）

## 🎯 仓库用途

本仓库用于：

- 🐛 **Bug 追踪**: 报告问题和技术故障
- 💡 **功能建议**: 提出新功能和改进意见
- 📋 **反馈收集**: 分享使用体验和建议
- 📢 **版本公告**: 获取版本发布和重要通知

## ✨ 主要功能

- 🔄 **跨浏览器同步**: 在多个设备间无缝同步书签
- 🔒 **安全存储**: 书签加密存储，确保数据安全
- ⚡ **实时更新**: 修改内容即时同步到所有已连接浏览器
- 🎨 **现代界面**: 基于 Vue 3 和 Element Plus 构建的简洁界面
- 🌐 **多语言支持**: 支持中文、英文等多种语言
- 📦 **导入/导出**: 轻松备份和恢复书签数据

## 🚀 安装方式

### Chrome 应用商店（即将上线）

扩展程序即将在 Chrome 应用商店上架。

### 手动安装

1. 从 [Releases](../../releases) 下载最新版本
2. 解压下载的文件
3. 打开 Chrome 浏览器，访问 `chrome://extensions/`
4. 在右上角启用"开发者模式"
5. 点击"加载已解压的扩展程序"，选择解压后的文件夹

## 🏗️ 技术栈

- **框架**: Vue 3 + TypeScript
- **UI 组件库**: Element Plus
- **构建工具**: Webpack 5
- **扩展标准**: Chrome Extension Manifest V3
- **架构**: 基于 Channel 的多进程通信系统
